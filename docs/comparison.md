# comparison

Returns a TileRule that checks a property of a location against a given value.

```sig
tileScanner.comparison(tileScanner.TileProperty.Column, tileScanner.ComparisonOp.Equals, 0)
```

## Parameters

* **property**: The location property to check
* **op**: The comparison operation to use on the location property
* **value**: The value to compare the location property against
