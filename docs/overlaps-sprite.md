# overlaps sprite

Checks if any location in an array overlaps with a given sprite.

```sig
tileScanner.overlapsSprite([], sprites.create(img`.`, SpriteKind.Player))
```

## Parameters

* **locations**: The locations to check for overlap
* **sprite**: The sprite to check for overlap with
* **map**: The map that the locations are in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
