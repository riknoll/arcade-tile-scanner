# filter locations

Filters an array of locations by a given TileRule.

```sig
tileScanner.filterLocations([], tileScanner.tileIs(img`.`))
```

## Parameters

* **locations**: The locations to filter
* **rule**: The TileRule to filter the locations by
* **map**: The map that the locations are in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
