# set tile at locations

Sets the tiles at multiple locations in a Tilemap

```sig
tileScanner.setTileAtLocations([], img`.`)
```

## Parameters

* **locations**: The locations to set
* **tile**: The Image of the tile to set at the specified locations
* **map**: The map to set the locations in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
