# calculate metric

Calculates a metric for a group of locations, such as their bounding box dimensions or position.

```sig
tileScanner.calculateMetric([], tileScanner.LocationGroupMetric.PixelWidth)
```

## Parameters

* **locations**: The array of locations to calculate the metric for
* **metric**: The metric to calculate
* **map**: The map that the locations are in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
