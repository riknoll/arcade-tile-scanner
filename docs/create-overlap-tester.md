# create overlap tester

Creates a sprite that can be used to test for overlaps with the bounding box of a group of locations. This sprite will cover the entire bounding box of the locations.

```sig
tileScanner.createOverlapTester([], SpriteKind.Player)
```

## Parameters

* **locations**: The array of locations to create the bounding box for
* **kind**: The kind of sprite to create
* **map**: The map that the locations are in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
