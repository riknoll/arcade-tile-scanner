# index of location

Finds the index of a location within an array of locations. Returns -1 if not found. This function compares locations by their column and row values, not by reference.

```sig
tileScanner.indexOfLocation([], tiles.getTileLocation(0, 0))
```

## Parameters

* **locations**: The array of locations to search
* **toFind**: The location to find

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
