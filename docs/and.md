# and

Returns a TileRule that matches locations that are matched by all of the argument TileRules.

```sig
tileScanner.and(tileScanner.tileIs(img`.`), tileScanner.isWall())
```

## Parameters

* **arg1**: A tileScanner.TileRule
* **arg2**: A tileScanner.TileRule
* **arg3**: A tileScanner.TileRule
* **arg4**: A tileScanner.TileRule
* **arg5**: A tileScanner.TileRule
* **arg6**: A tileScanner.TileRule
* **arg7**: A tileScanner.TileRule
* **arg8**: A tileScanner.TileRule
* **arg9**: A tileScanner.TileRule
