# update tiles

Updates the locations outlined by a TileOutlineSprite.

```sig
tileScanner.updateTiles(tileScanner.createOutlineSprite([], 2, 1), [])
```

## Parameters

* **outlineSprite**: The TileOutlineSprite to update
* **locations**: The new array of locations to outline

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
