# create outline sprite

Creates a sprite that outlines a group of tile locations.

```sig
let myOutlineSprite = tileScanner.createOutlineSprite([], 2, 1)
```

## Parameters

* **locations**: The array of locations to outline
* **color**: The color of the outline
* **thickness**: The thickness of the outline

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
