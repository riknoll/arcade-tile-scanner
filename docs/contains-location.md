# contains location

Checks if an array of locations contains a specific location. This function compares locations by their column and row values, not by reference.

```sig
tileScanner.containsLocation([], tiles.getTileLocation(0, 0))
```

## Parameters

* **locations**: The array of locations to check
* **toFind**: The location to find

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
