# matches rule

Checks a location in a Tilemap to see if it is matched by a given rule

```sig
tileScanner.matchesRule(tiles.getTileLocation(0, 0), tileScanner.tileIs(img`.`))
```

## Parameters

* **location**: The location to check
* **rule**: The rule to check the location against
* **map**: The map that the location is in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
