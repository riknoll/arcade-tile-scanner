# get all matching locations

Returns all locations in a tilemap that match a given rule.

```sig
tileScanner.getAllMatchingLocations(tileScanner.tileIs(img`.`))
```

## Parameters

* **rule**: The rule to filter locations with
* **map**: The map to scan for locations in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
