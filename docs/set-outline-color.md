# set outline color

Sets the outline color of a TileOutlineSprite.

```sig
tileScanner.setOutlineColor(tileScanner.createOutlineSprite([], 2, 1), 3)
```

## Parameters

* **outlineSprite**: The TileOutlineSprite to set the color of
* **color**: The new outline color

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
