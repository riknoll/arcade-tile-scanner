# borders

Returns a TileRule that checks if a location borders another location that matches a given TileRule.

```sig
tileScanner.borders(tileScanner.tileIs(img`.`))
```

## Parameters

* **rule**: The TileRule to check bordering locations for
* **mode**: The type of bordering locations to be checked

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
