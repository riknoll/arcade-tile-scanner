# set wall at locations

Sets the wall state for all locations within an array in a Tilemap

```sig
tileScanner.setWallAtLocations([], true)
```

## Parameters

* **locations**: The locations to set the wall state of
* **isWall**: Whether the locations should be walls or not
* **map**: The map to set the wall state in

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
