# set outline thickness

Sets the outline thickness of a TileOutlineSprite.

```sig
tileScanner.setOutlineThickness(tileScanner.createOutlineSprite([], 2, 1), 2)
```

## Parameters

* **outlineSprite**: The TileOutlineSprite to set the thickness of
* **thickness**: The new outline thickness

```package
arcade-tile-scanner=github:riknoll/arcade-tile-scanner
```
